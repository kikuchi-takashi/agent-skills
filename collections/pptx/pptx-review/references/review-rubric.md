# 監査基準 — 何を、どの重大度で指摘するか

## 重大度

| 重大度 | 定義 | 例 |
|---|---|---|
| 重大 | 受け手が必ず気づき、内容の信頼を損なう。納品不可 | 文字のはみ出し・切れ、キャンバス外の要素、開けない、数値の捏造の疑い、仮置き文言 |
| 重要 | 見る人の一定数が気づき、「雑」「AIっぽい」と感じる | 飾り線・色帯、同型カード、絵文字、誇張語彙、話題ラベル型タイトル、同一レイアウトの連続、最小サイズ未満、余白の侵食、重なり |
| 軽微 | 並べて見れば分かる。単独では気づかれにくい | 0.05in の整列ずれ、間隔の不均一、ea 書体の欠落、出典の書式のばらつき |

重大が1件でもあれば「要修正」。重要は原則すべて修正対象だが、利用者の意図（テンプレ由来など）が確認できたものは「意図的」として報告に残す。

## lint のコード

| コード | 重大度 | 意味 |
|---|---|---|
| BROKEN_RELATIONSHIP / SLIDE_PART_MISSING / CONTENT_TYPE_MISSING / CONTENT_TYPES_MISSING | 重大 | パッケージの整合が壊れている（開けないか修復ダイアログ） |
| PLACEHOLDER_TEXT | 重大 | 仮置き文言（ダミー、TODO、ここに入力、要確認 など）が残っている |
| OUT_OF_CANVAS | 重大 | 要素がスライドの外に出ている |
| TEXT_OVERFLOW_LIKELY | 重大 | 文字が箱に収まらない見込み（推定。画像で確定） |
| FONT_TOO_SMALL | 重大 | 出典以外の文字が下限未満（注記を含む下限: 講演型 14pt、資料型 12pt。出典は 9pt）。本文の下限（講演型 18pt、資料型 14pt）は目視で確認 |
| TEXT_OVERFLOW_POSSIBLE | 重要 | 収まりがぎりぎり。画像で確定 |
| TEXT_OVERLAP | 重要 | テキスト要素同士の重なり |
| FULL_PAGE_PICTURE | 重要 | 1枚の画像がページの85%以上を占める（編集不能の疑い） |
| TEXT_SHAPE_COLLISION | 重要 | テキストが塗り面・画像・図表と部分的に重なっている（容器に収まっているものは除く） |
| TITLE_POSITION_DRIFT | 重要 | タイトルの位置か幅が、他のページの多数派と違う |
| TITLE_SIZE_DRIFT | 重要 | タイトルのサイズが多数派と違う |
| MARGIN_DRIFT | 重要 | 内容の左端が多数派の揃え線から 0.15in 以上ずれている |
| BODY_SIZE_DRIFT | 重要 | 本文の主たるサイズが型スケールから3pt以内で外れている（明確に違うサイズは密度の設計判断として見ない） |
| FORM_FAMILY_MONOTONE | 重要 | 同じ形式ファミリーが本文の半分を超える。主役が回っていない |
| DECORATION_REPEATED | 重要 | 本文領域の同じ位置に飾り（罫線・帯）が過半数のページで繰り返されている |
| SHAPE_TEXT_UNSTYLED | 重要 | 図形の中の文字に書体かサイズの指定が無い。受け手の環境の既定になって崩れる |
| CONNECTOR_DETACHED | 重要 | 線の端点が図形に接していない |
| CONNECTOR_DIAGONAL | 重要 | 斜めの直線で図形を結んでいる。段がずれているなら直角に折る |
| PALETTE_DRIFT | 重要 | 既存の文字色に近いが違う文字色を使っている（面・線の色差は設計判断として見ない） |
| CHART_NEGATIVE_RENDER | 重要 | 負の値の棒に invertIfNegative が無い。PowerPoint 以外のビューアで負の棒が上向きに見える |
| ACCENT_LINE_UNDER_TITLE | 重要 | タイトル直下の飾り線 |
| COLOR_BAND | 重要 | 上端・下端の全幅色帯 |
| SIDE_STRIPE | 重要 | 側面の縦帯 |
| CARD_EDGE_STRIPE | 重要 | カード左縁の帯 |
| EMOJI | 重要 | 絵文字・記号装飾 |
| AI_VOCAB | 重要 | 誇張・抽象語彙 |
| TITLE_TOPIC_LABEL | 重要 | 話題ラベル型タイトル（表紙・目次・章扉は除外して判断） |
| TITLE_TOO_LONG | 重要 | タイトルが全角36字超（予算は30字） |
| TITLE_ORPHAN_LINE | 重要 | 折り返したタイトルの最終行が全角3文字未満。1文字だけ落ちた見出しは雑に見える |
| TEXT_DENSE | 重要 | 1枚の文字量が上限超 |
| LAYOUT_REPEATED | 重要 | 同一レイアウトが3枚連続 |
| LAYOUT_MONOTONE | 重要 | 同一レイアウトが本文の50%超 |
| MIXED_FONTS | 重要 | 書体が4種類以上 |
| DESIGN_LOCK_FONT / DESIGN_LOCK_COLOR | 重要 | ロックに無い書体・色 |
| CARD_ROW | 軽微 | 同型の塗り面が3枚以上横並び（内容の数と一致すれば可） |
| EQUAL_EMPHASIS | 軽微 | 同じ大きさの大きな文字が3つ以上、等分に並ぶ。主役が決まっていない（等価なら表にする） |
| TYPE_SIZE_COUNT | 軽微 | 1ページの字の大きさが5種以上。階層ではなく無秩序になっている |
| DARK_PAGE_OVERUSE | 軽微 | 濃い一色面のページが4枚以上。区切りとして働かず地になっている |
| FULL_WIDTH_RULE | 軽微 | 全幅の罫線（フッター1本なら可） |
| MARGIN_TIGHT | 軽微 | テキストが余白 0.4in に入り込んでいる |
| NO_EA_FONT | 軽微 | 和文 run に ea 書体が無い |
| EMPTY_PLACEHOLDER | 軽微 | 空のプレースホルダ（編集画面に入力促進文が出る） |
| MISALIGNED | 軽微 | 他の要素が共有する揃え線から 0.03〜0.15in ずれた端 |
| CORNER_MIX | 軽微 | 角丸と直角の塗り面が同じページに混在 |
| AUTOFIT_SHRINK | 軽微 | 自動縮小で収める設定。縮小後のサイズは FONT_TOO_SMALL で別途判定 |
| SHAPE_TEXT_TOP_ANCHORED | 軽微 | 図形の中の文字が上に貼り付いている。余りがあるなら上下中央に |
| DEAD_WHITESPACE | 軽微 | 本文領域の 55% 超が空いている。下や右に偏った空白なら見直す |

推定に基づくコード（OVERFLOW 系）は、画像で確認してから重大度を確定する。要約の `measured` は実フォントで折り返しを測った結果、`estimated` は文字幅の概算である。lint は placeholder の継承位置を近似しており、テンプレ由来のスライドでは位置が取れない要素がある。`design-lock.json` の `allow` で登録された指摘は判定から外れるが、各項目に空でない `reason` が必須である。理由が無ければ設定エラーとして終了する。

統一性の指摘（`*_DRIFT`）は本文ページ4枚以上のときだけ働き、表紙・章扉は除外する。多数派との比較なので、元から揃っていないデッキでは既存ページにも出る。編集の監査では `--baseline` で元の状態を渡し、新しく増えたものだけを見る。新形式のレポートはOOXML上のスライド部品パス・コード・図形名で照合するため、タイトル変更や並べ替え後も同じスライドを追跡できる。部品パスを持たない旧レポートだけ、タイトル・コード・図形名で照合する。

**咎める向きは2つある。** `*_DRIFT` は静かな層（色・書体・余白・タイトル位置）が揃っていないこと、`FORM_FAMILY_MONOTONE` と `LAYOUT_MONOTONE` はうるさい層（レイアウト・主役）が変わっていないことを指す。片方だけを直すと、揃っているが単調なデッキか、変化はあるが散らかったデッキになる。レポートの `form_families` に主役の内訳が出る。

## 目視の順序と観点

### ページごと

1. **はみ出し・切れ**（重大）: 箱の外の文字、最終行の欠落、図表ラベルの切れ。代替書体での描画なら、ぎりぎりは溢れると判定
2. **重なり**（重要）: 文字の上の線、図形に隠れた文字、図表ラベル同士
3. **出典・フッターと本文の衝突**（重要）
4. **余白と間隔**（重要/軽微）: 余白 0.6in、要素間 0.3in。片側の空白、下 1/3 の空き
5. **整列**（軽微）: 列の端、箱の端、タイトルの左端が他のページと同じか
6. **コントラスト**（重要）: 本文 4.5:1、大きな文字 3:1
7. **視覚の兆候**（重要）: 飾り線、色帯、縦帯、カード縁の帯、同型カード、アイコン入りの丸、グラデーション、光彩、絵文字、巨大数字の反復、まとめ帯、パレットの装飾使用
8. **文章の兆候**（重要）: 話題ラベル型タイトル、誇張語彙、三点セット、両論併記、体言止め連発、敬体常体の混在、感嘆符、捏造の疑い
9. **主張と展示物**（重要）: 1枚1主張か、展示物は1つか、読み取りの一文があるか、数字に出典があるか
10. **編集可能性**（重要）: 全面画像のページ、画像化された図表や文字

### デッキ全体

- タイトル位置・余白・フッターの一貫性（lint の `*_DRIFT` と、描画の一覧で確認する）
- 主役が回っているか（`form_families` の内訳。1つが半分を超えていないか）
- リズム: 密なページの後に余白のページがあるか、濃い面が3回までか
- 目を細めるテスト: 一覧画像を縮小して、各ページに主役が見えるか
- 同一レイアウトの連続と比率（40%超は指摘）
- 主役（図・文・数字・表）が回っているか
- 濃い面のページの回数（3回超は指摘）
- 強調色の配分（毎ページ同じ場所、または特定ページに集中）
- ゴーストデッキテスト
- 結論・依頼で終わっているか
- ノートの有無（講演型で無ければ指摘）

## 判定できないもの

- 数値・引用の真偽。「出典の記載が無い」「裏付けの表示が無い」までを指摘する
- 受け手の環境での書体の見え方。指定書体と代替の可能性を報告する
- 利用者の意図（テンプレ由来の装飾など）。「テンプレに由来する可能性」と書き、判断を利用者に返す

## 書き方

- 件数と場所で書く。「概ね良好」「気になる点はない」は書かない
- 各指摘に修正案を1つ付ける（削除、移動、文言の書き換え案）
- 見ていないものは「未確認」と書く
