# 既存デッキから生成AIらしさを取り除く

「AIっぽいので直して」と言われたときの手順。対象を列挙して利用者に見せてから実行する。消す判断は「その要素を消して意味が減るか」で行う。減らなければ装飾である。

## 1. 対象の列挙

pptx-review の lint があれば通し、`ACCENT_LINE_UNDER_TITLE`、`COLOR_BAND`、`SIDE_STRIPE`、`CARD_EDGE_STRIPE`、`CARD_ROW`、`EMOJI`、`AI_VOCAB`、`TITLE_TOPIC_LABEL`、`LAYOUT_REPEATED`、`LAYOUT_MONOTONE` の指摘をページ・図形名つきで表にする。無ければ描画画像を見て次を探す。

| 探すもの | 見分け方 |
|---|---|
| タイトル下の飾り線 | タイトルのすぐ下、幅がタイトルより短い細い線や矩形 |
| 上下の色帯 | ページ幅いっぱいの塗り矩形。上端か下端 |
| 側面の縦帯 | ページ高さいっぱいの細い塗り矩形 |
| カード左縁の帯 | カードの左端に沿った細い塗り矩形 |
| 同型カード3枚 | 同じ大きさの角丸矩形が横並び |
| アイコン入りの丸 | 小さな円の上にアイコン、右に見出しと説明 |
| グラデーション・光彩 | `gradFill`、`glow`、`softEdge` |
| 絵文字・記号 | 🚀✅✨ など |
| 毎ページの「まとめ帯」 | 下部の全幅の塗り面に一文 |
| 話題ラベル型タイトル | まとめ、概要、課題、〜について |
| 誇張語彙 | シームレス、革新的、〜を実現、〜を推進、シナジー |
| 巨大な数字の反復 | 毎ページに 60pt 超の数字 |

## 2. 視覚の修正

| 対象 | 修正 |
|---|---|
| 飾り線、色帯、縦帯、カード縁の帯 | 図形を削除。空いた場所は詰めず余白として残す |
| 同型カード | カードの塗りと枠を消し、見出しの位置と余白で区切る。内容の数が3でないなら列数を内容に合わせる |
| アイコン入りの丸 | 円とアイコンを消し、見出しと説明だけを表か箇条書きにする |
| グラデーション背景 | 単色（テーマの背景色）に |
| 光彩・ぼかし・影 | `effectLst` を空にする。python-pptx では `shape.shadow.inherit = False` |
| 絵文字・記号 | 文字から削除 |
| まとめ帯 | 削除。結論は結論ページに集約 |
| 巨大な数字の反復 | 主張を支える2〜3枚だけ残し、他は本文サイズに戻す |
| 同じレイアウトの連続 | 主役を変える（図・文・数字・表）。内容が同じ形なら表1枚にまとめる |

削除した図形の分だけ他の要素を動かさない。余白が増えて読みやすくなる。動かすのは、明らかに片側に寄ってしまったときだけ。

## 3. 文章の修正

- タイトルを主張の一文に書き換える。書き換えられない（主張が無い）ページは、削除候補として利用者に示す。
- 誇張語彙を、その語が隠している具体（数値・対象・期限）に置き換える。分からなければ「要確認」と付けて利用者に問う。捏造しない。
- 三点セットは内容の数に戻す。並列の「さらに」「また」は要素を減らす。
- 両論併記は立場を取り、反論は「前提とリスク」に隔離する。
- 敬体と常体を統一する。感嘆符と「※」の多用を消す。

文章の変更は意味を変える。差し替え前後の対照表を作り、利用者に見せてから反映する。

## 4. 変えないもの

- テンプレ由来の装飾（利用者の資産）。飾り線や色帯がテンプレのマスターにある場合は、利用者に「テンプレ側にある」と伝えるに留める
- 表の見出し行の罫線、フッターの罫線1本
- 主張を支える強調色1か所
- 内容の数が本当に3のときの3列比較

## 5. 確認

- lint の該当指摘が消えていること（元からあった指摘との差分で確認）
- 描画画像で、削除跡に不自然な空白の偏りが無いこと
- ゴーストデッキテスト（タイトルだけで論旨が通る）
