# 設計の原則 — 良いスライドはどこが違うか

`anti-ai-checklist.md` は避けるものを書いている。こちらは**作るもの**を書く。禁止だけを守ると、白地に黒文字の無難なデッキに行き着く。それは「AIらしくない」が「設計されてもいない」。

## 1. 主題からデザインを導く

デザインは外から様式を貼るのではなく、主題が持っている言語から引き出す。

作業は3行で始まる。

1. このデッキは何についてのものか（具体的な主題を1つ）
2. その主題の世界には、どんな素材・道具・記号・図版があるか
3. そのうち、紙の上で使えるものはどれか

物流なら伝票の罫線、路線図、コンテナ番号の等幅数字。医療なら計器の目盛、白と一本の赤。金融なら台帳の罫線と桁の揃った数字。製造なら図面の寸法線と断面。研究なら注釈の付いた図版と脚注の作法。

**判定**: このデザインに別の主題を流し込んでも成立するなら、まだ設計されていない。テンプレートを選んだだけである。

主題から引けないとき（抽象的な経営テーマなど）は、聴衆の場から引く。役員会なら台帳と罫線、現場説明なら図面と番号、社外発表なら余白と一枚の写真。

## 2. 不均等に投資する

1枚のスライドで、**1つの要素を120%、残りを80%**にする。すべてを均等に整えたページは、整っているが何も言っていない。

- そのページが「何のためにあるか」を決め、それを担う要素を1つ選ぶ。図か、数字か、一文か、写真か
- 選んだものを大きく、強く、余白を与える
- 残りは静かにする。説明文は小さく、補助線は淡く、ラベルは控えめに

デッキ全体でも同じことをする。全ページを均等に作り込むより、3枚を強く作って残りを整えるほうが、見た人の記憶に残る。

**判定（目を細めるテスト）**: 描画画像を縮小して、文字が読めない状態で見る。主役・見出し・支える要素・細字の3〜4段が区別できれば階層がある。全部が均一な灰色に見えるなら、主役がいない。

## 3. リズムを設計する

デッキは1枚ずつ見るものではなく、送りながら見るものである。連続して見たときの変化が、内容の構造を伝える。

3つの拍を意図的に置く。

- **色の拍**: 濃い面のページ（表紙・章扉・宣言）を3回まで。等間隔に近い位置に置くと、区切りとして働く
- **密度の拍**: 密なページの後に、余白の多いページを1枚。息継ぎがないと、後半が読まれない
- **主役の拍**: 図 → 文 → 数字 → 表 → 図、と主役を回す。同じ形式が本文の半分を超えたら、内容が求める形に作り直す

拍は「変化のための変化」ではない。内容の切れ目と一致させる。章が変わるところに濃い面を置き、結論の直前に余白を置く。

## 4. 静かな層は繰り返し、うるさい層は変える

統一と変化は対立しない。**層が違う。**

| 層 | 扱い | 具体 |
|---|---|---|
| 静かな層（繰り返す） | 全ページ同じ | 配色、書体、型スケール、余白、タイトルの位置、フッターの体裁、罫線の太さ、角の処理 |
| うるさい層（変える） | ページごと | レイアウトの原型、主役の種類、密度、要素の数、図の形 |

デッキが「一つの設計物」に見えるのは静かな層のおかげで、「読み進められる」のはうるさい層のおかげである。逆にすると壊れる。装飾を全ページに同じ形で押すと、それは統一ではなく騒音になる。レイアウトを全ページ同じにすると、それは統一ではなく単調になる。

## 5. シグネチャを1つ持つ（主題から作る）

このデッキを思い出すときの手がかりを、1つだけ決める。**既製の装飾から選ぶのではなく、主題の世界から作る。** これがデッキを「テンプレートでないもの」にする唯一の要素である。

シグネチャは、次の4つを満たして初めて署名になる。満たさないものは装飾である。

1. **主題由来である。** 物流なら伝票の罫線と番号、医療なら計器の目盛、金融なら台帳の締め線、研究なら取得点と未取得点。色帯・飾り線・光彩・グラデーション・アイコン入りの丸・角丸カードの反復は、どのデッキにも付けられるので署名にならない。
2. **1つの形に1つの意味。** その形が2つのことを指し始めたら、読み手はどちらとも読まなくなる。「太線＝実測」と決めたら、強調にも太線を使わない。
3. **初出で意味を言う（見知らぬ人テスト）。** 見たことのない形は、説明が無いと飾りに見える。最初に出るページに一行の凡例を置く（`engine-notes.md` の `motif_legend()`）。凡例なしで通じるなら、それは既製の形であって署名ではない。
4. **3つの層で働く。** 署名が1ページの飾りで終わるなら、それは署名ではなく1枚の装飾である。

| 層 | 出し方 | 回数 |
|---|---|---|
| 静かな標識 | ページの定位置に置く小さな印。全ページ同じ位置・同じ大きさ | 全ページ |
| 幾何そのもの | **そのページの構造がモチーフそのものになっているページを1枚**。台帳なら締まらない収支、被覆なら取得点と未取得点の格子 | 1枚 |
| 凡例 | 初出のページに一行 | 1回（回数に数えない） |

**強く出すのは3回まで。** 表紙・章扉・結び、あるいは幾何そのもののページと結び。全ページに強く押すと、署名ではなく壁紙になる。

**判定**: この署名を別の主題のデッキに移せてしまうなら、主題から作られていない。

## 6. 余白は設計であって余りではない

余白は「まだ埋めていない場所」ではなく、視線の置き場所である。

- 主役の周りは広く空ける。狭いと主役に見えない
- 余白は偏らせてよい。左に寄せて右を大きく空けるのは、均等に配るより意図が伝わる
- ページの下 1/3 が空くのは、たいてい設計の失敗ではなく**内容の不足**である。要素を増やすのではなく、その主張が1枚に値するかを疑う
- 埋めたくなったら、要素を足すのではなく主役を大きくする


## 7. 型は「照合」ではなく「選択」で決める

設計とは、当てはまる形式を探すことではない。**内容が取りうる形式を2〜3個出し、決め手で選ぶ**ことである。

最初に当てはまった形式をそのまま採ると、同じ形がデッキ中で繰り返され、テンプレートに流し込んだ見た目になる。各ページで一行残す——**「候補: A / B。選: A。理由: 〜」**。理由が書けないなら、まだ選んでいない。

### 第一手: 内容の形から視覚言語を引く

形式の名前（比較、手順、指標）から入らない。**その内容がどんな形をしているか**を先に言葉にする。

| 内容の形 | 視覚言語 |
|---|---|
| 流れる | 導管、川、搬送 |
| 詰まる | 隘路、絞り |
| 積み上がる | 地層、階段 |
| 分岐する | 分水嶺、決定木 |
| 循環する | 軌道、はずみ車 |
| 集まる・散る | 放射、集約 |
| 覆う・抜ける | 網、篩、取得と未取得 |
| 対になる | 天秤、継ぎ目 |
| 伸びる・縮む | 曲線、山、目盛 |

「工程が4つある」ではなく「3つ目で詰まっている」と言えたなら、選ぶのは等分の4箱ではなく、絞りが見える形になる。この一手を飛ばすと、内容がどうであれ同じ箱が並ぶ。

### 第二手: 候補を出し、決め手で選ぶ

| 内容 | 候補（2〜3） | 決め手 |
|---|---|---|
| 差を見せる | 比較（左右）／表／対比（`before-after`） | 対象が2つで軸が1つなら左右。軸が2つ以上なら表。**前後の状態そのものが主張**なら対比 |
| 変化を見せる | 推移（`line`）／対比／大きな数字（差分） | 時点が3つ以上なら推移。2時点なら差分の数字1つ。過程ではなく状態の違いが主張なら対比 |
| 順序ある動き | 手順（`steps`）／工程（`roadmap`）／流れ（`flow`）／箇条書き | 日付があるなら工程。**律速や変えた箇所があるなら流れ（その工程を主役に）**。番号だけで足りるなら手順。順序に意味が無いなら箇条書き |
| 量が主張 | 大きな数字／指標（`metrics`）／棒 | 主張が1つの数字なら大きな数字。**複数でも主役は1つ**（`metrics(hero=)`）。並べて比べるのが主張なら棒 |
| 内訳 | 円（5区分まで）／積み上げ棒／表 | 割合が主張なら円。総量も要るなら積み上げ棒。値を照合させるなら表 |
| 関係・分類 | 構造（2×2）／図（箱と線）／表 | 二軸で位置が意味を持つなら2×2。つながり方が主張なら箱と線。属性の一覧なら表 |
| 並列の項目 | 箇条書き／表／カード | **まず量（`metrics`）・二軸（構造）・比較（表）が無いか疑う。** それらが無く、項目が並列・無順序・等重みのときだけカード |
| 一つの主張 | 一文（`statement`）／大きな数字＋一行／図まるごと＋主張タイトル | 言葉が主張なら一文。数字が主張なら数字。図が証拠なら図を大きく、タイトルで読み取りを言う |
| 場・人・物 | 写真（`photo-full` / `photo-half`）／図 | 実物を見せる必要があるときだけ写真。無いなら図。**雰囲気のための写真は装飾** |

**カードは反射で選ぶ形ではない。** 角丸の面に囲んだ項目を並べる形は、**並列・無順序・等重み**の項目に対してだけ正しい。内容に順序・量・関係・時間・二軸のどれかが1つでもあるなら、カード以外の形がほぼ常に強く言える。`box_text()` の `fill` の既定が `None` なのはこのためで、面を敷くのは選択である。

**等分も反射で選ぶ形ではない。** N 個を横に並べる前に、どれが主役かを決める（`emphasis(n, hero)`）。主役が決まらない N 個は、そもそも横並びにする内容ではない。

### 第三手: 写真と図表を、内容が求める形で選ぶ

**写真**は、場・人・物を見せる必要があるときだけ置く。飾りの風景写真は装飾であり、§8 の判定（消して意味が減るか）で落ちる。置くときは裁ち落とし（`photo-full`）か片側（`photo-half`）を使い、文字を重ねるなら薄い面（`scrim`）を必ず挟む。画像に直接文字を置くと読めない。

**図表**は伝えたいことで選ぶ。骨格の `chart(..., kind=...)` が7種を持つ。

| 伝えたいこと | kind |
|---|---|
| 量の比較 | `bar` |
| 内訳つきの比較 | `bar_stacked` |
| 時間による変化（3時点以上） | `line` |
| 積み上がる変化 | `area` |
| 全体に対する割合（系列1つ、5区分まで） | `pie` / `doughnut` |
| 項目名が長い比較 | `bar_h` |

円は5区分まで。それ以上は棒にする。系列は3本までで、主張を支える系列だけ主色にし、他は罫線色に落とす。

### 原型の一覧（第二手で選んだ後に引く）

| 伝えたいこと | 原型 |
|---|---|
| 1つの根拠を示す | 主張＋証拠 |
| 前提と本体を分ける | 非対称分割（1:2） |
| 差を見せる | 比較 |
| 量そのものが主張 | 大きな数字 |
| 論の転換を宣言する | 一文 |
| 精密な値を照合させる | 表 |
| 順序ある行動を頼む | 手順 |
| 区切りを作る | 章扉 |
| 変化を見せる | 推移（`trend`） |
| 関係・分類を示す | 構造（`structure`） |
| 場・人・物を見せる | 写真（`photo-full` / `photo-half`） |
| 判断を仰ぐ | 結論・依頼 |
| 時期と段取りを見せる | 工程（`roadmap`） |
| 変化そのものを見せる | 対比（`before-after`） |
| 複数の数字を並べる | 指標（`metrics`） |
| 参照用に残す | 付録（`appendix`） |

内容が求めていない型を選ばない。3つ並べたいから3列にするのではなく、比較対象が3つあるから3列にする。

## 8. 最後に1つ取り除く

各ページで、いちばん要らない要素を1つ見つけて消す。余分な罫線、3つ目の色、誰も読まないラベル、意味のない番号。

**判定**: それを消して意味が減るか。減らないなら装飾である。この工程で崩れるページは設計されておらず、装飾されていた。

## 9. 迷ったときの順序

1. 主張は1つか。2つあるなら分ける
2. **形式を2つ以上考えたか。** 1つしか出していないなら、それは選択ではなく照合である
3. 主役は決まっているか。決まっていないなら、このページは何のためにあるか
4. 主役は十分大きいか。小さいなら大きくする
5. **面（カード）と等分を、反射で使っていないか。** どちらも「そう決めた理由」が言えるときだけ
6. 静かな層は他のページと同じか
7. 前後のページと比べて、密度と色に変化があるか
8. 消せる要素はないか

見栄えを良くしたくなったら、足す前にこの8つを通す。ほとんどの場合、答えは「主役を大きくして、他を消す」になる。

デッキ全体では、これに1つ足す。**署名は主題から作ったか、既製の装飾を選んだか。** 後者なら、そのデッキはまだテンプレートである（§5）。
