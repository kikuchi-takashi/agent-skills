# 構成の作り方 — 聴衆の状態を動かす順番に並べる

スライドは情報の入れ物ではなく、聴衆の状態を「前」から「後」へ動かす道具である。構成は、その道筋を1枚ずつ区切ったものになる。

## 1. 前後の状態を書く

`outline.md` の冒頭に3行で書く。

- **前**: 聴衆がいま何を知っていて、何を疑っているか
- **後**: 終了時に何を信じ、何を決め、何をするか
- **障害**: 前から後へ移るのを妨げる、最大の疑問や反論

この3行が書けない主題は、まだスライドにできない。利用者に聞く。

## 2. 骨格を1つ選ぶ

| 骨格 | 向く場面 | 順番 |
|---|---|---|
| 結論先行 | 経営層、時間が短い、判断を求める | 答え → 根拠1〜3 → 前提とリスク → 依頼事項 |
| 状況・問題・解決 | 提案、変化を説得する | 共有済みの状況 → 決断を迫る変化 → 証拠つきの打ち手 |
| 問い・答え | 調査報告、学術 | 問い → 方法 → 結果 → 含意 |
| 時系列 | 経緯説明、振り返り | 起点 → 転機 → 現在 → 次 |

骨格は混ぜない。「まず背景、次に課題、最後にまとめ」という並びは骨格ではなく目次であり、聴衆を動かさない。

## 3. 1枚ごとの定義

各ページに次を書く。

| 項目 | 内容 |
|---|---|
| タイトル | 主張を一文で（後述） |
| 役割 | 骨格の中でどこを担うか（答え／根拠／前提／依頼 など） |
| 証拠 | 数値・事実・引用と、その出典。無ければ「要確認」と書く |
| 展示物 | 図・表・数字・文・写真のうち1つ。何を見せて主張を支えるか |
| 密度 | 講演型か資料型か、文字量の目安（後述） |
| 話者ノート | 声に出して言う内容。資料型でも要点を書く |
| 次への受け渡し | このページを見た聴衆が次に抱く問い |

## 4. タイトルは主張の一文

タイトルは「何の話か」ではなく「何が言えるか」を書く。

| 話題ラベル（避ける） | 主張の一文（こうする） |
|---|---|
| 市場概況 | 国内市場は横ばいだが、法人向けだけが年12%伸びている |
| 課題 | 解約の6割は導入3か月以内に起きている |
| 施策 | 導入初月の伴走を増やせば、解約は半分にできる |
| 今後の展望 | 来期は法人向けに投資を寄せ、個人向けは維持に回す |
| まとめ | 判断を仰ぎたいのは、伴走要員の2名増員である |

規則:

- 全角13〜30文字を目安に、最大2行。3行になるなら主張が絞れていない。
- 2行目が5文字未満になるタイトルは言い換える。1文字だけが2行目に落ちた見出しは、それだけで雑に見える。描画で確認する。
- 「〜について」「〜のご紹介」「〜の全体像」で終わらせない。
- 「〜が重要」「〜が求められる」は主張ではない。何がどうなるかを書く。
- 疑問形は、次のページで答える場合だけ使う。

**ゴーストデッキテスト**: タイトルだけを順に読み、それだけで論旨が通るか確かめる。通らないなら構成を直す。生成に進んではいけない。

## 5. 1枚1主張、1枚1展示物

- 1枚に主張が2つあれば分ける。証拠が重複して論を進めないページは統合する。
- 展示物は1つ。2つの図を並べたくなったら、本当に1つの比較か、2つの別の主張かを考える。
- 展示物には「何を読み取るか」を書き添える。図を置いて説明しないのは、聴衆に仕事を押しつけている。
- 主張を支える数字は図の上で目立たせる（色・太さ・注記）。探させない。

証拠の階層は上から順に: 主張のタイトル → 主証拠（展示物） → 補助証拠 → 解釈 → 含意・行動 → 出典。

## 6. 密度モードは2つ

| | 講演型 | 資料型 |
|---|---|---|
| 想定 | 話者が語り、スライドは補助 | 読んで完結。配布・回覧 |
| 本文サイズ | 18〜24pt | 14〜16pt |
| 1枚の文字量 | 全角120字まで | 全角250字まで |
| 箇条書き | 3〜5項目、各1行（全角20〜25字） | 5項目まで、各2行まで |
| 枚数 | 多め（1分1枚） | 少なめ |
| 注記・出典 | ノートへ | ページ下部に10〜11pt |

中間はない。どちらかに決め、収まらないなら文字を減らすか分割する。文字を小さくして収めない。

## 7. 話者テスト

各ページを、話者になったつもりで声に出して言う。

- 言えない（言葉が出てこない）ページは、主張がない。削るか書き直す。
- 言えるが、スライドを見なくても同じことが言えるページは、展示物が要らない。
- スライドの文をそのまま読み上げるだけになるページは、文が多すぎる。

## 8. 章立てと番号

章番号・目次・章扉は、内容に本当の区切りと順序があるときだけ使う。5枚のデッキに目次は要らない。15枚を超えたら章扉か進行表示を検討する。

## 9. 終わり方

最後のページは結論・依頼事項にする。質疑の間、画面に残るのはそのページである。「ご清聴ありがとうございました」だけのページで終わらない。付録は結論の後ろに置く。

## 10. 文字量の予算（和文、全角換算）

| 要素 | 講演型 | 資料型 |
|---|---|---|
| タイトル | 13〜25字 | 13〜30字 |
| 小見出し | 10字以内 | 15字以内 |
| 箇条書き1項目 | 20〜25字 | 40字以内 |
| 段落 | 使わない | 3行（全角90字）以内 |
| 図表の注記 | 20字 | 40字 |
| 出典 | ノートへ | 1行 |

英数字は半角で書き、全角換算 0.5 字と数える。
